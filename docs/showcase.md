# 云间 1.0.3 · 实际效果

截图与短视频来自独立 SillyTavern 1.19.0 的虚构测试对话，使用真实消息、菜单与外观扩展。手机画面为 390×844 浏览器视口。

## 浅色阅读

柔软气泡与加深的强调文字；用户回复靠右，角色正文随原生页面宽度变化。

![浅色软气泡](screenshots/desktop.png)

## 深色与调色

浅深色分别记忆配色，面板里可以继续调整字号、圆角和凹凸强度。

![石墨深色与外观设置](screenshots/dark-palette.png)

## 手机菜单

保留常用入口，点击「菜单」展开全部功能。

![手机阅读与菜单入口](screenshots/mobile.png)
