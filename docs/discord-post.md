# 云间 · 让酒馆界面柔和一点 ☁️

做了一套偏安静的新拟物美化「云间 / Cloud Correspondence」，想让长时间看对话时舒服一点。

- 浅色软气泡 / 石墨深色，也可以跟随系统。
- 十套配色，底色、强调色、字号、圆角和凹凸程度都能调。
- 桌面侧边菜单，手机用「菜单 / 收起」展开完整功能。
- 页面宽度会跟着调整正文阅读宽度。

这次 1.0.3 修好了左栏挡住悬浮入口和头像大图的问题，也把浅色模式的小字与选中态加深了。此前的通知图标平铺问题也已修复。

**安装分两步：**在酒馆「扩展 → 安装扩展」粘贴下面的仓库地址；再下载 Release 里的主题 JSON，在「用户设置 → UI 主题」导入。

扩展：https://github.com/demilich1117/cloud-correspondence

主题与视频：https://github.com/demilich1117/cloud-correspondence/releases/tag/v1.0.3

已有用户：更新扩展后，还要更新主题 CSS / JSON。想保留自己的页面宽度等设置，可以整段替换仓库里的 `themes/theme.css`，再保存当前主题。

顺便推荐一下制作它用的 **酒馆主题工作台**：在真实酒馆里拾取部件、直接微调，或标点写意见，和 Agent 一起把主题做下去。
